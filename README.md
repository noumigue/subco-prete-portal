## Getting Started

First, run the development server:

```bash

# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Release flow

Use this command to publish current `dev-pilotes` changes to `main`:

```bash
npm run release:main
```

Le script effectue:
- vérification d'arborescence propre
- `git fetch`
- bascule sur `dev-pilotes` si nécessaire
- bascule sur `main`
- merge avec `--no-ff` et commit de merge
- `git push origin main`
- retour automatique sur `dev-pilotes`

If you use another dev branch, run:

```bash
npm run release:main -- ma-branche
```

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
